# WormSoft Limit Monitor

Расширение для Chrome, которое мониторит остаток лимита провайдера **WormSoft** (ai.wormsoft.ru).

## Возможности

- Опрос `GET https://ai.wormsoft.ru/api/v1/account/limits` **каждые 5 минут** (через `chrome.alarms`, работает даже с закрытым окном).
- Остаток кредитов прямо на **иконке в тулбаре** (`2.2M`, `850k`…):
  - зелёный — норма,
  - оранжевый — подписка заморожена (`isFrozen`, действуют лимиты Free),
  - красный — кредиты кончились, `!` — ошибка (невалидный ключ, rate limit и т.д.).
- **Popup** с деталями: остаток по тарифу и бусту, тайминги сброса («через 3 ч 20 мин», при наведении — точная дата), тип подписки, предупреждение о заморозке, **приближённый процент использования тарифа** (см. «Ориентир по тарифу» ниже).
- **Ориентир по тарифу**: endpoint не возвращает размер полного лимита подписки, поэтому расширение само запоминает **максимальный зафиксированный** остаток `subscriptionLimit` (самое большое наблюдаемое значение с момента смены тарифа) и показывает процент «использовано» от него. При изменении `subscriptionType` (смена/заморозка тарифа) память сбрасывается, и ориентир определяется заново. Значение хранится локально в `chrome.storage.local` (`quotaMemory`).
- **Настройки** (вкладка): URL эндпоинта, API-ключ.
- Кнопки «Проверить сейчас» в popup и на странице настроек.

## Установка (dev-режим)

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (правый верхний угол).
3. «Загрузить распакованное расширение» → выберите эту папку.

## Настройка

Откройте иконку расширения → «⚙ Настройки» (или `chrome://extensions` → «Подробнее» → «Настройки расширения»).

| Поле | Что указать |
|---|---|
| URL эндпоинта | По умолчанию `https://ai.wormsoft.ru/api/v1/account/limits` (документация: https://ai.wormsoft.ru/docs/account/limits) |
| API-ключ | Тот же ключ, что и для LLM endpoint-ов; отправляется в заголовке `Authorization: Bearer <ключ>` |

Ключ хранится **только локально** в профиле браузера (`chrome.storage.local`).

## Формат ответа API

```json
{
  "userId": 123,
  "subscriptionType": "payed",
  "subscriptionLimit": 1234567,
  "subscriptionLimitResetAt": 1730000000,
  "boostLimit": 1000000,
  "boostLimitResetAt": 1730003600,
  "totalLimit": 2234567,
  "isFrozen": false
}
```

Все поля `*Limit` — это **остатки**: endpoint не возвращает размер полного лимита, поэтому точный процент невозможно показать — только абсолютные числа и приближённый «ориентир» по наблюдаемому максимуму (см. «Ориентир по тарифу»).

Обрабатываемые ошибки API: `401` (невалидный ключ), `429` (rate limit), `404` (запись пользователя удалена).

## Ограничения

- Опрос каждые 5 минут. По документации endpoint можно дёргать хоть каждый запрос — при желании уменьшите `CHECK_INTERVAL_MIN` в `background.js`.
- Endpoint отдаёт только остатки, поэтому бейдж показывает абсолютное число кредитов. Процент «использовано» в popup — **ориентир** (наблюдаемый максимум, см. выше), а не точный размер лимита: пока расширение не увидит полный остаток после сброса периода, значение может занижать реальный лимит.
- Разрешение на сеть выдано только `https://ai.wormsoft.ru/*`. Если поменяете эндпоинт на другой хост — добавьте его в `host_permissions` в `manifest.json` и перезагрузите расширение.
