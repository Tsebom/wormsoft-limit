WormSoft Limit Monitor

Настройки подключения к API провайдера WormSoft.

Документация: https://ai.wormsoft.ru/docs/account/limits. Запрос GET с заголовком Authorization: Bearer <ключ>.
Тот же ключ, что и для LLM endpoint-ов. Хранится локально в этом браузере (chrome.storage.local) и отправляется только на указанный URL.
Можно задать любое количество порогов. Уведомление придёт, когда totalLimit опустится до значения порога или ниже — по каждому порогу по одному алерту (повторный алерт по тому же порогу — после возврата остатка выше него).
